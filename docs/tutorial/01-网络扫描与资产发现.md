# lightx

项目调用命令：`lightx`

安装：

```bash
pip install lightx
```

如果你的系统不允许直接使用 `pip install`，可以改用用户目录安装：

```bash
pip3 install --user lightx
```

说明：该工具在项目中默认为 `enabled: false`。安装完成后，如果要让 CyberStrikeAI 调用它，需要把 [tools/lightx.yaml](/home/zhaoshuai/workspace_cyber/LNU-SecLLM/tools/lightx.yaml:4) 中的 `enabled: false` 改为 `enabled: true`。

简单测试：

```bash
lightx -t 127.0.0.1
```

验证：

```bash
lightx --help
```
