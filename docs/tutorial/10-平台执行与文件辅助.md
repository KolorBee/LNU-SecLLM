# exec

项目调用命令：`sh -c`

用途：执行系统 Shell 命令，适合测试 AI 是否能正确调用本机命令并读取结果。

安装：

```bash
sudo apt update
sudo apt install -y bash coreutils
```

验证：

```bash
sh --version
```

简单测试：

```bash
sh -c "pwd && whoami && uname -a"
```

注意：`exec` 可以执行任意命令，联调 AI 时建议只在本机课程环境或靶场环境使用。

# create-file

项目调用命令：`python3`

用途：通过项目内置 Python 脚本创建文件，适合测试 AI 的文件写入能力。

安装：

```bash
sudo apt install -y python3
```

验证：

```bash
python3 --version
```

测试建议：让 AI 在 `/tmp` 或项目 `tmp/` 目录下创建一个测试文件，例如 `/tmp/cyberstrikeai-tool-test.txt`。

# modify-file

项目调用命令：`python3`

用途：通过项目内置 Python 脚本修改文件，适合测试 AI 的文件更新能力。

安装：

```bash
sudo apt install -y python3
```

验证：

```bash
python3 --version
```

测试建议：先用 `create-file` 创建 `/tmp/cyberstrikeai-tool-test.txt`，再让 AI 追加或替换一行内容。

# delete-file

项目调用命令：`rm`

用途：删除文件，适合测试 AI 的清理能力。

安装：

```bash
sudo apt install -y coreutils
```

验证：

```bash
rm --version
```

测试建议：只删除明确创建的临时文件，例如 `/tmp/cyberstrikeai-tool-test.txt`，不要让 AI 删除项目文件。

# execute-python-script

项目调用命令：`/bin/bash` + `python3`

用途：执行一段 Python 脚本，适合测试 AI 是否能完成结构化计算、JSON 处理、文件统计等任务。

安装：

```bash
sudo apt install -y bash python3
```

验证：

```bash
bash --version
python3 --version
```

简单测试：

```bash
python3 -c "import json; print(json.dumps({'status':'ok'}, ensure_ascii=False))"
```

# install-python-package

项目调用命令：`/bin/bash` + `pip`

用途：安装 Python 包，适合测试 AI 是否能补齐轻量依赖。

安装：

```bash
sudo apt install -y python3-pip pipx
```

验证：

```bash
pip3 --version
pipx --version
```

测试建议：优先安装小型、安全、常见依赖，例如 `requests`。不建议在联调阶段让 AI 安装大型依赖。

# query_execution_result

项目调用命令：`internal:query_execution_result`

用途：CyberStrikeAI 内部工具，用于查询工具执行结果，不需要安装系统命令。

安装：不需要单独安装。

验证：启动 CyberStrikeAI 后，在工具列表中确认 `query_execution_result` 已加载。

测试建议：先让 AI 执行一个会产生结果的工具，例如 `exec`，再让 AI 查询刚才的执行结果。
