# angr

项目调用命令：`python3` 内置脚本

用途：Python 二进制分析框架，常用于符号执行、路径求解、CTF 逆向和漏洞分析。

安装：

```bash
pip3 install --user angr
```

如果系统阻止 `pip3 install --user`，可以使用虚拟环境：

```bash
python3 -m venv ~/.venvs/reverse-tools
source ~/.venvs/reverse-tools/bin/activate
pip install angr
```

验证：

```bash
python3 -c "import angr; print('angr ok')"
```

# gdb

项目调用命令：`gdb`

用途：Linux 下常用调试器，用于调试 ELF 程序、分析崩溃、配合 PWN 题调试利用过程。

安装：

```bash
sudo apt update
sudo apt install -y gdb
```

验证：

```bash
gdb --version
```

简单测试：

```bash
gdb -q -ex quit
```

# gdb-peda

项目调用命令：`gdb`

用途：GDB 插件，提供寄存器、栈、反汇编、ROP 辅助等更适合 PWN/逆向的调试界面。

安装：

```bash
git clone https://github.com/longld/peda.git ~/peda
echo "source ~/peda/peda.py" >> ~/.gdbinit
```

验证：

```bash
gdb -q -ex quit
```

说明：如果启动 GDB 后能看到 `gdb-peda$` 风格提示符，说明 PEDA 已加载。

# radare2

项目调用命令：`r2`

用途：命令行逆向分析工具，支持反汇编、调试、补丁、脚本化分析。

安装：

```bash
sudo apt install -y radare2
```

如果软件源版本太旧，可以从源码安装：

```bash
git clone https://github.com/radareorg/radare2.git ~/tools/radare2
cd ~/tools/radare2
sys/install.sh
```

验证：

```bash
r2 -v
```

简单测试：

```bash
r2 -q -c "i" /bin/ls
```

# libc-database

项目调用命令：`python3` 内置脚本/本地库

用途：根据泄露函数地址或 libc 特征匹配 libc 版本，常用于 PWN 题和漏洞利用分析。

安装：

```bash
mkdir -p ~/tools
git clone https://github.com/niklasb/libc-database.git ~/tools/libc-database
cd ~/tools/libc-database
./get ubuntu debian
```

验证：

```bash
ls ~/tools/libc-database
```

简单测试：

```bash
cd ~/tools/libc-database
./find printf 0x0
```

说明：`./get ubuntu debian` 会下载较多 libc 数据，耗时取决于网络情况。如果课程只需要工具命令存在，可以先完成 clone，后续按需要再下载数据库。
